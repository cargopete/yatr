# yatr

A task runner in Rust: tasks in `yatr.toml` form a graph, and results are cached on declared inputs. One binary, `src/main.rs`; the same modules are also a library, `src/lib.rs`, so a new module is declared in both.

- The `yatr.toml` schema, the CLI and its flags, and the cache's on-disk and wire formats have been frozen under semver since 1.0. Change them by adding, never by altering. A new subcommand goes in `YIELDING_BUILTINS` in `src/cli.rs`, so a task of the same name still wins. The library API and the plugin ABI are not frozen.
- A change to what the cache key is made of costs every user a rebuild. `Cache::key_inputs` in `src/cache.rs` must keep producing the keys it produces now.
- Behaviour is tested through the binary, in `tests/`. Add the test with the change.
- User-visible changes go in `CHANGELOG.md` under Unreleased, and in `README.md` and `docs/book/src/` where they are documented.
- stdout carries what tasks print and what a command was asked for; status, warnings and errors go to stderr. Print through `outln!` and `errln!` in `src/output.rs`, not `println!`, which panics on a closed pipe.

## Tasks

This project's build, test and lint commands are [yatr](https://github.com/cargopete/yatr) tasks, defined in `yatr.toml`. Run them through yatr rather than calling the tools directly: a task whose inputs have not changed is restored from cache instead of run again.

- `yatr run --agent <task>...` runs tasks and prints one line per task. For a failure it adds the failing command, its exit code and the last lines of its output; the whole output is in `.yatr/logs/<task>.log`.
- Before reporting work as done, run `yatr run --agent ci` and fix what it reports.
- `yatr explain <task>` says whether a task would run or come from cache, and which inputs changed.
- `yatr affected <git-ref>` lists the tasks that changes since a ref can affect.
- `yatr run --json <task>...` and `yatr list --format json` are the machine-readable forms.
- To add or change a task, edit `yatr.toml`, then run `yatr check` and `yatr agents --write`.
